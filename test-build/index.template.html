Maintained static test site

Patchstack connector build test

This small Vite application lets you watch the UUID move from the first scan into source, through the compiler, and finally into the generated static HTML.

Run the test in this order

  1. 1
    Provision and inject npm run patchstack:scan

    Reload the development preview after the command finishes.

  2. 2
    Compile the static site npm run build

    The scan runs before Vite and the output marker runs afterwards.

  3. 3
    Serve the generated files npm run preview

    Open the printed address and confirm the disclosure button is visible.

Expected result

Both the generated source page and dist/index.html should contain one managed CDN tag carrying the same security-sensitive local test UUID.
